Explanations:
1. sigalarm:
The syscall stores the alarm interval, current tick, a trapframe, flag alarm and pointer to handler in the process structure. On each tick, the kernel increments a current tick. When current tick equals the interval, the current process state is saved using the stored trapframe, and execution is redirected to the handler and the flag alarm is set to true. The current tick is reset.

2. sigreturn:
The syscall restores the previously saved registers and program counter from the process structure, clears the “alarm” flag, and resumes execution exactly where the process was interrupted returning the a0 register which is the return value for functions.
